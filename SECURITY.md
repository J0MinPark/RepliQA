# Reporting a security issue

Contact Jeongmin at jeneric873@gmail.com. Do not open a public issue containing
tokens, customer data, exploit credentials, or a live private target.
Use a local synthetic reproduction and describe the affected version and impact.

This is experimental QA software, not a security scanner or an authorization
boundary for an untrusted website. Only test sites you are authorized to test.
Current target guards do not constitute proof against every DNS-rebinding or
network-isolation attack. Unrestricted public target registration remains closed.

No security certification or guaranteed response SLA is currently offered.
