# Cloud 0.2.4 실제 브라우저 재검증 완료

2026-09-18 KST. RTX 4060 서버에서 검증 명령을 실행하고, 배포된 인증 API를 통해 **실제 Cloudflare Browser Run**에서 두 검사를 수행했다. 로컬 Chromium의 결과를 클라우드 검증으로 대체하지 않았다.

기존 장애였던 axe.source 번들 함수의 `__name` 오류는 이번 실제 배포 실행에서 재현되지 않았고 접근성 엔진 결과가 정상 수집됐다. 이 테스트는 예제 사이트에서의 배포 확인이며 전체 WCAG 적합성, 모든 고객 사이트의 정확성, 제3자 독립 평가 완료를 뜻하지 않는다.

## 무료 예산 처리

제공사 원격 browser binding의 limits/history/sessions를 읽었다. 시작 전 실제 사용량은 15.548초, 두 검사 후 누적 사용량은 26.219초였다. 종료 후 활성 브라우저는 0개다. 응답 시간에는 API 처리 등도 포함되므로 제공사 브라우저 과금 시간과 동일하지 않다.

원래 RepliQA 전역 4회 중 2회가 남아 있었으나 운영자 계정의 기본 2회 제한을 사용한 상태였다. 사용자의 요청에 따라 기존 운영자에게 남은 2회를 일회성 예약으로 배정했다. 전역 4회·동시 1회·접수 간격·인증·입력 지문 검증은 유지했고, 이전 기록을 삭제하거나 새 계정을 만들지 않았다. 기본 고객별 제한은 바꾸지 않았다. 현재 전역 사용 기록은 4/4회다.

따라서 앞서 남아 있던 출시 절차 **① 실제 배포 브라우저 재검증은 완료**다. 제3자 독립 평가, 운영 격리·복구 시험, 실제 고객 반복 사용은 별도로 남아 있다.
